# Wake-word training inputs

Status: trained, not released. These are the inputs of the licence-clean pipeline
in `pipeline/` (README.md), which trained "Hey Mirrin", "Hey Nyra" and "Hey Pickoo".
Nothing here is shipped or embedded. This inventory does not cover or relicense the
old "Hey Maverick" model, which releases don't ship; its history is in
../../docs/wake-word.md. It is for the replacement pipeline only, not the legacy
personal-training scripts under docs/.

The JSON block is the machine-readable inventory: every file the pipeline reads,
including evaluation data and each individual voice, with its exact licence, a
fixed-revision source, licence evidence, SHA-256 and attribution. `recipe.yaml`
lists exactly the same ids. The rows are generated by `pipeline/make_inventory.py`,
whose table holds the reviewed facts; the script only adds checksums. Strict lint
(`python3 -B tools/wakeword/lint_licences.py`) checks the records, and `--data DIR`
checks the local bytes. Passing lint is not legal clearance or release acceptance.

Deliberately not used: ACAV100M and every openWakeWord precomputed feature set
(CC BY-NC-SA 4.0), openWakeWord's pre-trained wake models, macOS `say` voices
(Apple terms), Piper voices with non-permissive or unclear lineage (lessac and
anything fine-tuned from it), the real RIRs and point-source noises in OpenSLR 28,
MUSAN files whose own licence is BY-SA, BY-NC or other, and Common Voice (its
downloads now sit behind an account and terms gate).

Open caveats for release review:

- openWakeWord's README places "included pre-trained models" under CC BY-NC-SA 4.0.
  The two front-end files used here are checked by `pipeline/verify_frontend.py`: the
  melspectrogram model holds only textbook DSP constants, and every learned weight in
  the embedding model is Google's Apache-2.0 speech_embedding/1 (batch-norm folded).
  The upstream author has not yet confirmed this in writing
  (dscripka/openWakeWord#348, open).
- Kokoro's model card says it was trained on permissive and non-copyrighted audio,
  and that this includes synthetic audio generated by closed commercial TTS models.
  The weights are Apache-2.0, but whether any of those providers' terms reach
  Kokoro's output is the publisher's statement, not something this pipeline can
  verify. Piper voices carry no such note.
- Kokoro and Piper phonemise with espeak-ng (GPL-3.0) at synthesis time. It is a
  tool run on our own text; no espeak-ng code or data is in a model.
